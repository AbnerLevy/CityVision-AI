# 🏙️ CityVision-AI: Sistema Multiagentes para Planejamento Urbano Sustentável

**CityVision-AI** é um ecossistema de automação inteligente baseado em **arquitetura de múltiplos agentes autônomos (Multi-Agent Workflows)**, desenvolvido como projeto prático para o curso de **Engenharia de Prompt** da **Residência Tecnológica Accenture + Porto Digital**.

O objetivo da ferramenta é apoiar gestores públicos, urbanistas e comunidades no diagnóstico socioambiental e no planejamento de intervenções urbanas sustentáveis, integrando dados locais e inteligência artificial generativa.
